## 文件结构
- `src/index.html / styles.css / app.js`：三栏阅读工作台、订阅管理、文稿、解析、对话、设置。
- `src/core.mjs`：字幕解析、输入规范化、上下文分段与检索、转义和 Markdown 安全显示。
- `connector/server.py / yt_worker.py`：回环服务、随机认证、yt-dlp 子进程、定时工作队列、原子持久化。
- `start-connector.cmd / start-connector.ps1`：保留可见终端诊断及依赖修复入口。
- `connector/background.py / manage-connector.ps1 / start-connector-silent.vbs`：无控制台启动、当前用户登录启动项安装/取消、状态与优雅停止；enable/disable CMD 提供双击入口。
- `tests/core.test.mjs / tests/ui-harness.html / connector/test_server.py`：针对性测试与隔离 UI 模拟。

## 已实施协议
回环端口 18743；连接器把随机 {url,token} 写入独立数据目录 connector/connection.json，由 sdk.files 读取。实际业务请求均 Bearer 认证；CORS OPTIONS 只返回空预检响应。
GET /health；GET /library；POST /channels {url}；POST /sync {channelId?}；DELETE /channels/:id 保留资料；PATCH /settings {intervalMinutes,autoCaptions}；POST /videos/:id/transcript 排队；GET /videos/:id/transcript 读取字幕。
前端每 5 秒更新状态，无变化不重绘；模型请求只能由用户触发。
