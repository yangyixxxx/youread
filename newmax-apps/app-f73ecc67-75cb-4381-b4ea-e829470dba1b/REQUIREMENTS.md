# 映读 · 产品需求

## 已确认
用户需要输入 YouTube 频道，订阅新视频，获取字幕，AI 生成解析，围绕文稿对话阅读。用户已选择本地连接器方案：允许在本应用目录配置连接器；连接器运行时定时更新；2026-10-15 用户进一步要求自动静默启动，采用当前 Windows 用户登录启动项；AI 仅由用户点击发起。

## V1 主路径
- 输入 @handle、YouTube 频道 URL 或 UC 频道 ID；本地订阅管理、立即刷新、定时检查、重复订阅处理。
- 首次抓取最多 20 条近期视频；后续检查近期条目并去重，不承诺归档频道全部历史。默认每 30 分钟检查。自动尝试最新 3 条新视频的中/英文字幕，其余可手动获取；常规同步不下载视频媒体；仅在显式获取图文截图时按需读取媒体，不绕过登录或访问限制。
- 视频列表有频道筛选、标题搜索、未读/收藏筛选。选中视频进入文稿/解析/对话工作区。
- 字幕支持自动字幕、人工字幕，以及导入 SRT/VTT/TXT；有时间戳时可定位到原视频。没有字幕/网络受限时保留清晰错误和导入入口。
- AI 解析包含摘要、关键观点、章节、可追问问题；对话只基于当前文稿与已生成解析，引用时间戳，不足时明确说明。长文分段解析，明确范围。通过 NewMax 当前模型调用，不保存供应商凭据；调用前提示云端传输和可能费用。
- 频道、视频和下载字幕保存在此应用独立数据目录；阅读状态、导入文稿、AI 结果和对话通过 NewMax data API 持久化。
- 暂未接入时也能导入文稿阅读，不使用示例冒充真实订阅。

## 本地连接器边界
Python 标准库 HTTP 服务 + 独立虚拟环境 yt-dlp；仅监听 127.0.0.1。随机令牌在数据目录生成，由 sdk.files 读取，不进源码。连接器不由 NewMax frontend 执行，由当前用户 Windows 登录启动项静默启动，也提供手动恢复和停用入口。关闭连接器停止后台更新，关闭应用不触发 AI。只处理用户可访问内容；不导入浏览器 Cookies。

## 验收条件
1. 可以校验并添加频道、查看同步状态、手动刷新和取消订阅，重复输入不会产生重复频道。
2. 本地连接器支持定时去重同步和可用字幕获取；真实网络受限时显示可恢复错误，不伪造视频或字幕。
3. 可导入 SRT/VTT/TXT 文稿，显示时间戳，搜索文稿并跳转原视频；无字幕有导入入口。
4. 视频可按频道、标题、未读和收藏筛选，阅读状态、导入内容和收藏在重载后保留。
5. 解析与对话使用 NewMax 模型配置，按当前文稿构建上下文；具备重复提交保护、长文范围提示和错误恢复，不自动产生费用。
6. 默认与窄窗口下主要控件可访问，空白/加载/错误/有内容状态清楚，品牌跟随应用设置。

## 2026-10-14 全文解析优先
- 默认一次提交完整文稿（包含时间戳），一次生成最终解析；不按字符数自动分段，不额外调用汇总。
- 当前宿主调用入口没有固定 prompt 字符上限，模型目录未提供可靠上下文容量；不宣称任意模型均能处理全文，不伪造容量检测。
- 输入超限或其他失败保留旧结果与文稿，不自动重试/切模型/切段。显式兼容分段入口用于容量不足或续接旧任务，点击前确认剩余请求数。
- 旧 summaryParts 按原来的分段方式续接；全文解析不读取这些摘要替代原文，也不删除它们。兼容汇总保留完整分段摘要，不再每段截取前 800 字符。
- 全文解析使用宿主支持的 180 秒请求超时（仅本次任务）；界面说明等待边界，关闭窗口不能保证取消。输出额度仍由现有设置控制。
- 本轮只优化概览解析；阅读对话的相关片段检索保持原有范围提示，不宣称对话已改为全文。

## 2026-10-14 空正文故障修正
- 单次 AI 输出额度默认 8000 tokens（当前宿主接口上限），设置允许选择 4000 / 8000；未配置的旧资料自动采用新默认，不改动已选模型。
- 空 SSE / 空正文错误保留原始原因，说明无法单凭错误确定输出额度或协议兼容性问题；显示失败阶段、已完成分段及续接入口。
- 应用层不自动重试、不自动换模型；不得承诺失败请求不计费。测试只使用隔离 SDK，不调用付费模型。
- 保留已有字幕、分段解析、最终解析和对话；改动完成后刷新预览使新代码生效。

## 2026-10-14 解除低额度与完整性修复（覆盖上述旧额度约定）
- 用户已授权同时修复 NewMax 宿主工程；不改 Strata 思考配置，不自动重新生成。
- 默认 maxTokens='auto'，不再沿用旧 4000/8000 设置。可显式输入自定义正整数上限，不以 192K 直接作为输出额度；自动预算受协议、真实上下文剩余空间及服务端能力约束。
- 必须检测新版宿主能力，旧宿主时阻止生成并提示重启，避免 'auto' 被旧接口降为 1024。解析与问答等待默认 15 分钟，设置允许调整。
- 真实结束原因为正常停止且有正文才记为完成；额度耗尽、超时、未知状态或错误均保留已返回部分正文为未完成草稿，保留旧解析与分段，不自动重试。
- 旧解析缺少结束状态时明确标注“完整性未确认”，不凭标点猜测已完成，也不修改历史正文。
- 阅读问答也提交完整文稿、完整解析和已有对话，不再静默截成 12000 字符、5000 字符或最近六条；超限报错而不静默删减。

## 2026-10-14 Markdown 阅读样式
- 概览解析、AI 对话回复与未完成草稿支持标题、段落、粗体/斜体/删除线、有序/无序嵌套列表、引用、表格、分隔线、行内/围栏代码与安全链接。
- 时间引用保持定位文稿能力；代码块不误解析时间戳。表格和代码局部滚动，默认及 640×560 窗口不撑破页面。
- 只修改显示层；不改正文、解析进度、模型、输出预算、订阅及导出格式，不触发 AI 重新生成。原始 HTML 不执行，图片不自动联网加载。

## 2026-10-15 自动静默启动
- 当前 Windows 用户登录后通过专用启动项直接运行虚拟环境 pythonw.exe，无常驻终端，无管理员权限或宿主工程修改；现在立即启动。不是登录前系统服务。
- 沿用单实例锁；重复启动不重复同步，不改数据目录。启动失败写脱敏本地日志，不静默安装依赖，不终止未知端口占用者。
- 提供手动静默启动、停止和取消登录自启入口。停止采用经过原有认证的优雅关闭，保留队列和资料。
- 界面实时区分连接中、在线、离线，设置内同步状态变化不覆盖未保存的模型/同步表单；删除“必须保留终端”的旧说明。
- 自动启动只恢复订阅同步，不自动调用 AI。验证使用隔离临时目录；不注销/重启用户电脑来做验收。

## 2026-10-15 默认订阅阅读入口
- 每次打开应用，按订阅列表现有顺序选中第一个频道，并展示该频道视频列表中的第一条内容，不再优先恢复其他频道的历史选中项。
- 首频道尚无视频时保留该频道空状态，首次同步出视频后补选第一条；用户手动切换频道、视频、资料库筛选或搜索后，后台轮询不抢回默认项。
- 手动切换频道时同时展示该频道第一条视频，清空旧频道的搜索条件，避免列表和阅读区错配；空频道不显示上一频道正文。
- 自动展示不标记已读、不触发 AI，也不修改已有正文、解析或收藏。无订阅时沿用已有本地文稿入口。

## 2026-10-15 解析与对话流式展示
- 全文解析、兼容分段及阅读对话均通过宿主 ai.stream 接收真实正文增量；不模拟打字、不额外生成请求、不自动降级重试。
- 先订阅事件再发送请求，按 streamId 隔离；展示等待首段正文、输出中及完成/未完成状态，沿用自动预算、模型选择和用户等待设置。
- Markdown 增量渲染，局部刷新输出区，不重建输入框或打断用户向上阅读；切换视频不串文，返回可继续查看当前输出。
- 输出期间定期保存未完成草稿；正常终止后才写正式解析/对话。截断、超时、断线保留收到的正文与问题，不覆盖旧解析、不自动重试；关闭窗口不保证取消远端请求，最后尚未保存的增量可能丢失。
- 验收使用隔离事件模拟，不发起付费请求；流式改善可见反馈，不承诺模型更快结束思考或解决服务故障。

## 2026-10-15 流式权限修复
- 在应用权限清单显式声明 ai.stream，与已实现的流式解析/阅读对话一致；保留其它权限与用户资料。
- 修复后刷新窗口加载权限；验证重新生成的确认、取消、成功替换及失败保留旧解析，不替用户发起真实模型请求。
- 增加真实 manifest 权限回归，不仅验证模拟 SDK；不改模型、自动输出预算或 Strata 配置。

## 2026-10-15 原地流式替换
- 重新生成时直接使用原解析正文位置：隐藏旧正文和旧完整性提示，仅显示简洁等待状态；收到真实增量后在同一阅读列逐步展示 Markdown，不额外堆叠输出面板。
- 生成期间旧解析在本地保持不变，可通过默认收起的“查看上次解析”查看；只有正常完成才替换正式结果。失败有正文时原地保留未完成草稿、旧解析收起；没有正文时恢复旧解析。重载后维持同样规则。
- 对话输出使用普通助手消息样式；本次问题及回答位于历史消息之后，不再同时显示空状态、旧失败面板与新输出。未完成回复留在本次问题下方。
- 等待、输出、完成共用正文宽度和左右对齐；不重建输入框或强制拉回正在向上阅读的位置。仅调整展示，不更换模型、不修改额度、不替用户重新生成。

## 2026-10-16 中文粗体渲染兼容

## 2026-10-16 文章式精读与图文排版
- 解析提示词采用问题引入、分论点展开、原文例证、应用与边界、收束与追问；保持完整输入、自动预算、流式返回与真实终止保护。章节数量随资料，不机械凑十条，不虚构数字、案例、引语或亲身经历。应用推演明确标注，不把讲者主张写成已验证事实。
- 新增独立「图文排版」编辑器：从已有解析、未完成草稿、对话回复或原文复制，不覆盖原内容、不自动调用 AI。支持标题、署名/来源、Markdown 正文、字号、纸面、3:5/3:4/9:16 页面比例、预览与手动分页。
- 参照用户示例，默认暖白纸面、黑色宋体、大标题、宽留白、连贯段落；本地上传封面或正文配图，禁止从 Markdown 自动加载外部图片，不伪造视频截图或书封。纸纹是本轮生成的本地装饰素材，失败时可使用纯色纸面，不影响文字内容。
- 1080px 宽画布自动分页，不截短长正文；预览与 PNG 导出共用同一排版结果，支持单页 PNG 和全部分页 ZIP。表格转为逐行带列名的阅读文本，代码折行，图片保持完整比例。
- 排版草稿单独本地保存；重新打开恢复，保存失败明确提示，未保存关闭需确认。生成中的内容不能当完整文章导出；导入未完成草稿须带未完成标识。无生成请求、无自动模型费用。
- 验收使用隔离临时资料，不改写真实解析或订阅；覆盖编辑/分页/图片/导出/保存重载/失败/窄屏。真实模型文章质量不以模拟请求宣称已验证。

## 2026-10-16 问题驱动的知识文章（覆盖旧文章结构约定）
- 全文解析和兼容汇总以核心问题及读者理解顺序重构文章，不以视频介绍、逐段转述或清单为主线；章节表达具体判断，概念、案例过程、机制与边界自然推进，不强制每节同一模板。
- 减少重复的“讲者说”，但争议主张、人物经历、数据和引语须保持来源归属；不冒充作者经历、不将个案提升为普遍规律。方法应从原文论证中提炼；编辑整理标明“据原文整理”，延伸建议与原文结论区分。
- 不凭空创造案例、步骤、公式或命名模型；保留原文有效比喻、关键行动、转折、反例和条件。材料不支持方法论时忠实解释，不硬套成功学框架。
- 正文自然收束，不强制“值得追问”“回看索引”固定结尾；确有价值的追问/索引可作为文章后可选阅读补充，不新增独立UI。关键依据的原有时间引用保留，无时间戳不编造。
- 仅修改生成提示与相应测试，不修改排版界面、阅读对话策略、完整输入、自动预算、流式/失败保护或已有数据。不自动重写旧解析，不发起真实模型验收；真实成文效果需下次用户明确生成后评价。

## 2026-10-16 叙事口吻修正（覆盖上一版文风要求）
- 用户反馈“讲者称”“材料真正展示”仍像转述和审查报告。正文改为非虚构叙事：直接写人物处境、行动、转折与后果，再自然解释其中的道理，不由编辑站在外面评论材料。
- 真实性检查作为内部写作约束，不逐段输出“视频未提供证据”“这不能证明”等审计式评语。仍须保留会影响理解的重要不确定性、争议归属和限制，不能为故事流畅把自述写成独立核验事实；相同背景只交代一次，必要说明简短就近或放文末来源说明。
- 不补造现场、对话、心理或作者亲历。缺少故事的原文直接讲概念，不硬造故事；叙事服务理解，不退化成流水账或每节固定案例模板。边界尽量表述为具体条件，不机械设证据/局限栏目。
- 更新全文与兼容汇总角色、写作规则及回归测试；不改对话提示、UI、完整输入、预算、数据或既有解析，不代用户重新生成。

## 2026-10-16 图片隐藏时间引用
- 图文预览、单页 PNG 和分页 ZIP 不显示 `[0:22]`、`[4:29]` 等时间引用及以时间为文字的 Markdown 链接，避免文章中残留回看标记。
- 仅在图片排版时过滤；编辑底稿、已保存解析与对话保持原文，阅读页时间跳转保持可用。正常叙述中的时间、数字、普通链接文字及代码不删除；引用独占段落不留下空白段。

## 2026-10-16 订阅频道头像
- 订阅侧栏显示频道真实头像，沿用圆形尺寸、频道名、选中底色与同步状态点。头像由已有频道同步获取并持久保存，不用视频封面代替。
- 旧订阅在下次频道同步时补齐头像；本轮刷新现有频道信息使功能可用。缺失、网络失败或失效图片回退原字母圆标，无破图、不阻止阅读。
- 头像仅允许 HTTPS 的 YouTube 图片域，不接受任意脚本/本地路径，不发送 referrer；没有头像的同步结果不删除已保存头像。保留已有资料与登录自启，连接器修改后受控重启，不调用 AI。

## 2026-10-16 关键节点视频截图
- 用户选择“推荐位置，挑图后插入”：图文编辑器依据正文真实时间引用推荐约3–5处，不调用AI、不假装已理解画面内容；优先覆盖不同章节。允许修改时间点或无引用时手动指定当前位置。
- 用户显式获取后，连接器按这些时间读取可访问视频媒体并用FFmpeg生成真实JPEG截图；不以封面/缩略图冒充视频画面，不绕过登录或权限，不批量下载订阅视频。失败逐项显示、可调整后手动再试，不自动重试。
- 候选卡片展示画面、时间、对应段落和状态，用户勾选后才插入各自段落；正文变动导致锚点失效时阻止错误插入。截图保存到独立排版资产，可定位/移除，不覆盖原解析。
- 预览及PNG/ZIP中显示截图但不显示时间引用链接；来源视频ID与时间点作为编辑元数据保留。图片等比、正文自动续页，保存重开恢复。
- 网络流量和取帧等待在操作前明确；关闭编辑器停止等待，不宣称已取消后台任务。截图不送给云模型。仅支持连接器库内可访问视频；本地导入仍可上传配图。

## 2026-10-16 默认视频封面
- 打开图文排版时，默认获取当前 YouTube 视频封面并放在标题区域下、正文前；已有封面不覆盖。优先高清封面，明确不存在高清图时才读取标准封面，不用视频截帧冒充封面。
- 提供「获取视频封面」、自动获取开关、上传替换和移除。移除会关闭该草稿的自动获取，保存重开不会擅自加回；手动覆盖现有图先确认。
- 封面下载只访问固定 YouTube 图片域，不需要连接器或 AI。限制等待和体积，失败提示保留正文与旧封面，不循环重试；本地文稿可继续上传。
- 下载后转为本地图片资产，随排版草稿保存；重开复用本地图，PNG/ZIP 与预览一致且保持比例。关闭/停用自动获取时终止前端下载，迟到结果不得覆盖编辑。

## 2026-10-16 图文 H1 排版
- 用户要求H1更粗、尽量一行排下；不能一行时使用完整栏宽换行，减少右侧因均衡算法产生的空余。
- 文章主标题及正文Markdown H1使用更重宋体；短标题原字号，略长标题适度缩小以争取单行，长标题不无限缩小、不压扁、不裁掉。自动换行非末行适度两端对齐，末行自然左对齐；手动换行保留。
- 只调整图片显示与导出，正文、时间引用过滤、封面、阅读页、AI及已有草稿文字不改。

## 2026-10-16 章节标题修正
- 用户截图反馈章节标题仍提前断行且右侧留白过大；不能只修文章主标题/H1。图文中H1–H6统一使用加重宋体，取消次级标题的均衡缩栏，优先适度缩字单行，超长则按完整栏宽换行。
- 自动换行非末行适度两端对齐；末行与手动换行不强拉伸。保持各级基础字号、普通正文、原文与独立排版数据不变；以用户截图的完整句子做实际画布验证。
