# 美国节点字幕检查

本目录记录用户明确要求的有限节点检查，不是常驻自动扫描。

- 目标：当前库内的 `sGpCq_VsDkc` 视频。
- 范围：任务开始时 Clash「🇺🇸 美国手动」组中全部真实叶节点；排除 REJECT 等系统策略。
- 每节点最多一次详情与可用字幕下载，串行、起始间隔至少20秒、每节点最长90秒；尊重未结束的冷却，不循环重试。
- 只切换「映读字幕专用」组；测试期间暂停普通连接器避免串出口，结束后恢复。
- 报告中的 `attempted:false` 表示未实际网络检查，不能把它计为下载失败。`finished:true` 仅表示名单处理结束，不代表字幕下载成功。
- `ok:true` 仅在真实字幕下载且解析成功后记录；第一份成功字幕会补入当前视频，不覆盖已存在字幕。其余节点仍完成本轮检查。
- 不调用 AI 或付费接口，不记录 Clash 密钥、节点连接参数或签名字幕URL。
- 任务ID与报告去重；已有同任务报告不会自动重放。若要提前停止，在对应JSON旁创建同名 `.stop` 文件，等待当前有界请求退出。
