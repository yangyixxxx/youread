# 映读 · 设计系统

## 用户与任务
面向把 YouTube 作为学习资料的人；主路径是订阅、挑选视频、阅读时间轴文稿、生成解析、围绕原文追问。阅读区优先，不做统计仪表盘。

## 视觉方向
采用温暖的编辑型阅读桌：米白纸面、深墨正文、橄榄绿主操作、陶土色时间/提醒点缀。轻边线代替卡片套卡片。品牌图标为 menu_book/forest，不使用宿主组件或远程字体。标题适量采用系统宋体，正文系统无衬线。英文微型标签用于辅助层级而非替代中文。

## 布局与层级
- 顶部 64px 产品栏，品牌读取 bootstrap；右侧导入文稿与添加频道。
- 左侧 192px 导航：全部/待读/收藏、频道、连接器状态与设置。
- 中间 310px 视频列表：搜索、数量、刷新、缩略图与视频摘要行。
- 剩余区域为主要阅读区，选中视频后展示标题、来源、收藏/已读、概览/文稿/对话页签。
- 空状态提供添加频道、导入文稿两条真实入口和三步简明引导；不默认塞入演示数据。
- 1000px 以下左栏缩窄为 164px、视频列 270px；860px 以下转为侧栏抽屉、视频与阅读单栏切换。最小设计 640×560；长标题折行，工具栏可换行，不允许整页横溢出。

## 字体与间距
正文 14px/1.65，次要文字 12px，阅读正文 15px/1.9，主标题 22–28px。间距采用 4/8/12/16/24/32px；控制圆角 7px，弹窗 14px。按钮至少 34px 高；关键任务 40px。

## Markdown 阅读排版（2026-10-14）
- 延续米白纸面与橄榄绿，不更换品牌或三栏结构。概览、AI 回复和未完成草稿共用阅读排版；用户问题仍保留纯文本。
- 正文 15px / 1.85，正文色接近深墨；一级/二级/三级标题采用 25/21/17px，二级标题用细分隔线建立章节节奏。段落 14px、章节 28px 间距，不把每个原始换行拆成段落。
- 使用语义化有序/无序嵌套列表、引用、分隔线、表格、行内/围栏代码；引用为浅绿底与左边线，代码为低饱和灰绿底与等宽字体，表格独立横向滚动。
- 时间戳继续使用可键盘聚焦的引用按钮；代码、链接内部不生成跳转按钮。代码/表格滚动区可键盘访问，窄屏只局部滚动，不撑宽页面。
- 外部链接仅允许 HTTP(S)，另开且不传 referrer。原始 HTML 作为文字展示；图片仅显示说明，不自动请求外部图片。空/加载/未完成提示沿用现有组件，不美化成完成状态。
- 渲染本地完成，无 CDN、远程字体或模型请求；已保存原始 Markdown 与导出内容不变，不截取正文。
- 中文问题列表使用既有 strong 字重突出问题、后续解释保持普通字重。兼容中文标点与结束双星号前的横向空白，不展示多余的格式标记；不改变列表缩进、间距、颜色或品牌。流式未闭合标记先按原文展示，闭合后在原位加粗，不猜测补全文字。

## 图文排版编辑器（2026-10-16）
- 目标：把视频精读内容编辑成可分享的分页图文，而非生成一张带乱码的 AI 海报。原阅读工作台和品牌不变，入口在阅读页签旁，打开独立原生全屏 dialog。
- 编辑器顶栏显示名称、本地状态、保存与关闭；左侧 340px 可滚动编辑栏（内容来源→标题/来源→正文→配图与纸面），右侧深浅适中的灰米色预览台，一次看一页，页码与导出固定在工具栏。900px 以下改为编辑/预览切换，640×560 可使用全部控件，无整页横向溢出。
- 图片默认 1080×1800，边距72px，标题76px/1.35、二级标题50px/1.5、正文40px/1.8、段距28px；用户可调正文36/40/44px。字体使用本机 SimSun/Songti SC/Noto Serif CJK SC，界面沿用原无衬线。暖白 #fcfbf8、墨黑 #20221f，纸纹可关闭；正文不叠加卡片，页脚细线、来源与页码低对比。
- 封面标题后为可选封面图，正文按段落连贯排版；段落必要时逐行续页，标题尽量与后两行同页，不留孤标题；不裁掉图片和文字。手动分页用独立 ---；表格转带列名的行文本、代码保留字符并折行，提前在界面说明。
- 空态有正文输入引导；加载、排版中、保存/导出中、错误有明确状态。导出使用当前稳定预览，重排中禁用；旧图不冒充最新版本。配图只认本地资产标记，找不到时阻止导出并给出具体标记，外链图片仅显示说明。
- 图片纸面隐藏正文时间引用及纯时间链接，独占引用段落不占行；底稿保留引用，编辑栏提示“图片自动隐藏时间引用，阅读页跳转不受影响”。预览与导出使用相同过滤结果，保留正常时间叙述、代码、宋体层级和原有留白。
- 原文与排版副本分离，保存是显式操作；未保存关闭先给保留/放弃选择。Escape 与关闭一致；Tab 使用原生 modal 焦点管理，关闭返回入口。所有编辑操作不调用 AI。

## 订阅头像增量（2026-10-16）
- 将26px字母圆标替换为同尺寸真实频道头像，圆形裁切、object-fit:cover，布局与选中背景不变。图片是频道名旁的装饰，不重复屏幕阅读器名称。
- 加载阶段使用原字母/低饱和底色，成功后覆盖；缺图/失败移除图片露出字母，不显示破图，不挤压频道名或状态点。同一失败地址本窗口不反复重试，重新打开可重试。

## 关键节点截图（2026-10-16）
- 入口放在图文正文配图按钮旁：明确文字“从视频取图”。展开编辑栏内的候选面板，不新增聊天或独立应用导航。与现有米白/橄榄绿一致。
- 推荐卡片按章节顺序呈现：段落短摘→带标签的时间输入→16:9占位/真实画面→选择框和逐项状态；时间只在编辑器显示，不印到图片上。3–5张候选可纵向滚动，不横向堆积；640px编辑模式可完整操作。
- 点击“获取候选截图”才读取视频，先说明网络流量、仅视频库内内容、不用AI。等待有真实queued/running/逐项ready状态；失败保留已成功图、手动重试，缺依赖/离线/未找到引用提供具体下一步。
- “插入所选截图”显示数量，未选择/正在获取/正文锚点改变时禁用；插入后显示“已插入视频截图”，可定位标记或移除。关闭候选面板停止UI等待，不承诺取消后台；未保存插图由现有关闭确认保护。
- 图片使用原有等比完整显示、自动续页和PNG/ZIP同一画布；不得把缩略图当关键帧，也不让未插入候选进入导出。

## 默认视频封面（2026-10-16）
- 延续纸面/橄榄绿编辑器，在「纸面与配图」增加带可见标签的默认开启开关、获取视频封面主入口，上传与移除为次操作；按钮可换行，640×560不溢出。
- 封面状态就近显示等待、失败、已本地获取及尺寸，并提供小缩略图；图文纸面顺序保持标题/来源→等比封面→正文，沿用宋体、间距与自动分页。
- 获取时不锁正文编辑，保存/导出与封面替换暂禁用，关闭与取消自动获取可用；失败保留当前内容并恢复导出，无封面时允许继续排版。已有图不自动覆盖；移除关闭自动补图，保存后记住选择。

## H1 标题加重与满栏换行（2026-10-16）
- 仅图文图片的文章主标题及 Markdown H1：保留宋体，使用900字重并辅以极细同色描边，避免系统宋体无更粗字面时看不出区别；正文/H2及阅读页不改。
- 主标题基础76px，短标题保持原字号；略超一行时最多缩到64px争取一行，不无限压小。仍放不下一行则保持基础字号，按936px完整栏宽换行，取消H1缩窄行宽的均衡算法。
- 自动换行的非末行适度分配字间距贴齐左右边界，不拉伸字形；末行自然左对齐，不把少数字强拉满。手动换行尊重原意，英文保留单词，中文禁则保留。
- 预览和PNG/ZIP共用布局与绘制，不修改标题原文、正文或保存数据。

## 章节标题满栏修正（2026-10-16）
- 覆盖上节“正文/H2不改”的范围：文章标题及所有Markdown章节标题共用加重、有限缩字争取单行、完整栏宽自动换行规则。H1/H2保持50px、H3–H6保持44px基础层级，最多缩至基础字号84%，长标题不无限压小。
- 移除章节标题的均衡缩栏：截图“先决定业务要服务什么生活，再决定如何扩大它”必须使用936px完整正文栏，而非约60%栏宽。自动换行的非末行适度两端对齐，末行自然左对齐；手动换行保留。
- 保持正文40px、页边距、纸面、图片和保存接口，900字重及细描边用于所有章节标题，预览与导出一致。

## 状态与交互
- 流式生成在原正文位置替换显示，沿用米白/橄榄绿 Markdown 阅读列（最大960px、左右自动居中）；不新增横跨左侧的独立面板。单行低对比状态区分“等待正文 / 正在输出”，正文不套边框、底色或大段说明；没有正文时保留适量空间，不伪造内容。
- 生成中隐藏旧解析与旧完整性提示，旧正文放在默认收起的“查看上次解析”中；失败有正文时草稿继续占据同一主阅读位，无正文时恢复旧解析。草稿状态和详情独立于正文，错误色只用于状态，完整段落仍采用正常 Markdown。成功后移除生成状态，不新增第二份正文。
- 对话流式输出与已完成助手消息共用标签、字号和内边距；历史 → 本次问题 → 本次助手回复。开始生成即移除空状态，失败回复仍在本次问题后，不插到历史顶部。保持输入框和滚动行为，不导入 NewMax 宿主组件。
- 增量仅刷新当前输出正文，约80ms合并一次；不重绘输入框、不抢焦点。对话仅在用户靠近底部时跟随新内容，向上滚动后保留阅读位置。输出中不逐字ARIA播报，完成后沿用状态/错误提示。
- 首段即保存草稿，持续输出约每1.5秒保存一次；未正常结束的内容不能伪装完成。切视频不串流，返回原视频显示已收到正文。小窗口继承现有返回、换行与局部代码/表格滚动，不增加横向工具栏。
- 默认进入首个订阅频道及其首条视频，高亮沿用既有橄榄绿选中样式。首频道无内容时阅读区显示等候同步的空状态，不借用其他频道正文；视频到达后补选。默认展示不自动标记已读。窄屏自动进入阅读视图，保留“视频列表”返回入口；用户手动选择后轮询不抢焦点或重置阅读页签。
- 空/无搜索结果分别提供添加或清空筛选；连接器设置延续原 notice/米白/橄榄绿样式。连接中、在线、离线使用明确文字；独立状态区实时更新，不重绘未保存的设置。在线说明关闭阅读窗口仍同步，离线给出静默启动与日志路径；登录启动/取消入口为次要说明，不再要求保留终端。窄屏路径折行，停止操作先确认并说明下次登录仍会启动。
- 同步队列/字幕获取显示实际 pending/fetching 状态，失败保留原因与重试入口。
- AI 显示实际分段进度与错误；失败不自动重试，保留已完成分段；不显示假取消。
- 空正文错误沿用陶土色 notice，显示失败阶段、原始错误、模型与额度及“调整模型 / 输出额度”入口；费用提示不承诺服务商退款。概览长期显示已保存分段数和下一处理段。
- 输出预算位于现有设置的模型选择下方，默认“自动（不设应用固定上限）”，可切换自定义正整数；说明仍受模型/服务容量约束。等待时间以分钟设置。保持原品牌、字体、三栏布局和640×560窄屏策略。
- 阅读正文前用陶土色 notice 展示“未完成草稿”或“旧解析完整性未确认”；成功与未完成明确文字区分，不能仅靠颜色。部分结果完整显示并可导出，不覆盖旧笔记；历史结果与新草稿各自标注来源。宿主未更新时显示阻断说明，不发送请求。
- 概览以“全文一次解析”为唯一主操作，展示完整文稿字符数/1次请求/最长等待说明；分段变为次级 details“兼容分段”，有旧进度或模型输入超限时展开。旧进度明确是兼容任务，不暗示全文仍需14段。
- 分段执行先确认剩余分段与汇总次数；全文失败保留旧解析与旧分段，不自动启动兼容模式。成功页显示“全文单次 / 兼容分段”来源，重新解析默认全文并需确认。
- 导入使用带标签的标题、文件/粘贴区；支持 SRT/VTT/TXT。表单错误就近显示。
- dialog 使用原生焦点圈定与 Escape，Tab 焦点清楚，图标按钮有 aria-label，关闭返回触发控件。
- 所有文本经转义再渲染，模型输出不执行 HTML。字幕时间戳可作为跳转按钮，原视频链接另开。
- 对话固定底部输入框，显示“基于当前视频”与实际文稿范围；模型选择从实时目录取值。
